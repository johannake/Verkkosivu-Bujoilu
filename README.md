# Verkkosivu-Bujoilu
Bullet journaling -harrastuksesta kertova verkkosivusto (harjoitustyö)

Bullet journaling -ajankäyttötyökalusta ja siihen liittyvästä harrastuksesta kertova nettisivu. Sivu on tehty HTML:n ja CSS:n harjoitukseksi, joten se saattaa sisältää vanhentuneita ulkoisia linkkejä sekä osittain tarpeetonta tyylikikkailua.
Suora linkki sivustolle: https://johannake.github.io/Verkkosivu-Bujoilu/

Sivustosta on myös hyvin samansisältöinen WordPress-versio 
https://bujoilu.wordpress.com/
